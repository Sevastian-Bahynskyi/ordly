# Review alone owns retention measurements

Review is the only source of retention progress and review scheduling. Practice trains language skills but must never change Review cards, due dates, ratings, review history, or retention/mastery metrics, including when the learner chooses a mixed session.

This deliberately rejects the existing behavior that lets a rated practice recall task update a Review card. A mixed session may contain actual Review tasks, which keep their ordinary Review semantics, and Practice tasks, which cannot write Review progress. Retain internal, skill-specific practice history solely for future exercise selection; it must not create separate retention scores or memory rings, or change Review counters.

In mixed sessions, review a due word before practising that same word to avoid revealing its answer immediately before the Review test. Other items may be interleaved, provided actual Review tasks and Practice exercises remain clearly distinguished and only actual Review tasks receive scheduling ratings.
